ABOUT THIS PROJECT

研究のデータを、
触って確かめられる形に。

Steamゲームにおけるプレイヤー減少を調べる卒業研究から作った探索ツールです。Pythonで収集した時系列データとニュースを、同じ月を軸に照合できます。

コードと実行方法を見る ↗
01 / 指標

月間平均同時接続数は、その月に同時にプレイしていた人数の平均です。月間利用者数や個人単位の離脱率ではありません。

02 / 計算

前月比 ＝（当月平均 ÷ 前月平均 − 1）× 100。連続する月がそろい、前月平均が0より大きい場合のみ計算します。

03 / データの範囲

出典：SteamChartsおよびSteamニュース。保存済みデータのため、現在の状況を示すものではありません。

ニュースは研究時に収集した一部です。記事が表示されない場合も、出来事がなかったことを意味しません。
